# Дневник тренировок — Telegram Mini App

Личный дневник силовых тренировок (в духе Strong / Hevy / GymUp), который открывается прямо в Telegram.
Работает и в обычном браузере — это удобно для отладки.

- Все данные хранятся **на устройстве** (IndexedDB), интернет в зале не нужен.
- Резервная копия — в JSON-файл и в облако Telegram (CloudStorage).
- Тёмная тема по умолчанию, в Telegram подстраивается под тему пользователя.

## Стек

Vite, React, TypeScript, Dexie.js (IndexedDB), Recharts, dnd-kit (перетаскивание), Telegram WebApp SDK.
Шрифты Unbounded и Golos Text вшиты в сборку (@fontsource) — работают без интернета.

## Дизайн

Фон — графит резинового пола зала, текст — цвет мела, акцент — сигнальный оранжевый.
Группы мышц окрашены как соревновательные блины (грудь — красный, спина — синий, ноги — жёлтый,
плечи — зелёный, бицепс — белый…). На карточке тренировки её упражнения нарисованы «блинами на грифе»:
цвет — группа мышц, высота — число подходов. Цвета задаются CSS-переменными в `src/styles.css`.

## Как запустить у себя

Нужен установленный [Node.js](https://nodejs.org) (версия LTS).

```bash
npm install      # один раз: скачать библиотеки
npm run dev      # запустить локально → открыть http://localhost:5173
npm run build    # собрать готовый сайт в папку dist/
```

**Превью на телефоне:** http://localhost:5173/preview.html — приложение внутри макета iPhone 18 Pro Max
(рамка, уменьшенный Dynamic Island, шапка Telegram). Во время отдыха между подходами остров раскрывается
и показывает таймер, как Live Activity в iOS. Страница только для разработки, в сборку не попадает.

## Структура проекта

```
index.html               — страница, подключает Telegram SDK
src/
  main.tsx               — точка входа: запуск Telegram, темы и React
  App.tsx                — каркас: экраны + нижняя навигация
  styles.css             — все стили и цвета (CSS-переменные)
  db/
    types.ts             — модель данных (упражнения, шаблоны, тренировки, подходы, замеры)
    db.ts                — локальная база Dexie (IndexedDB)
    repo.ts              — операции с данными (сохранить, удалить, копировать)
    workout.ts           — тренировка: старт, подходы, завершение, рекорды
    stats.ts             — подсчёты для графиков и статистики
    seedExercises.ts     — встроенный справочник из 52 упражнений
  backup/                — резервная копия: файл JSON и облако Telegram (кусками по 4000 символов)
  workout/               — таймер отдыха, запуск тренировки
  nav/                   — навигация между экранами + кнопка «Назад» Telegram
  ui/                    — окна подтверждения
  telegram/
    telegram.ts          — обёртка над Telegram SDK (вибрация, свайпы, кнопки)
    theme.ts             — подстройка цветов под тему Telegram
  components/            — переиспользуемые элементы интерфейса
  screens/               — экраны приложения
```

## Модель данных

| Таблица        | Что хранит |
|----------------|-----------|
| `exercises`    | Справочник упражнений: название, группа мышц, оборудование, заметка, своё/встроенное |
| `templates`    | Шаблоны тренировок: список упражнений с подходами (3×8–12) и отдыхом |
| `sessions`     | Проведённые тренировки: дата, шаблон, начало/конец, заметки |
| `sets`         | Подходы: вес, повторы, разминочный/рабочий, выполнен |
| `measurements` | Замеры тела: вес, грудь, талия, бёдра, рука, бедро |

## Публикация (GitHub Pages)

Публикация автоматическая: файл `.github/workflows/deploy.yml` при каждой отправке изменений
в ветку `main` собирает приложение и выкладывает его на GitHub Pages.

1. В репозитории на GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Отправить изменения: `git push`.
3. Через 1–2 минуты приложение доступно по адресу `https://<имя-пользователя>.github.io/<репозиторий>/`
   (ход публикации — на вкладке **Actions**).

## Напоминания бота (сервер)

Папка `bot/` — небольшой сервер на Cloudflare Workers (бесплатный тариф):
`https://gym-diary-bot.aigymbot.workers.dev`.

- После тренировки приложение отправляет серверу короткую сводку (название, время, тоннаж, подходы, рекорды),
  и бот сразу присылает итоги. Полная история тренировок остаётся только на телефоне.
- Каждые 30 минут сервер проверяет, кому пора напомнить: «давно не было тренировки», «сегодня день тренировки»,
  «итоги недели» (воскресенье). Время и типы сообщений настраиваются в приложении: «Прогресс» → шестерёнка.
- Подлинность запросов проверяется по подписи Telegram (initData), токен бота хранится только в секретах Cloudflare.

Команды (в папке `bot`): `npx wrangler deploy` — опубликовать изменения сервера,
`npx wrangler secret put BOT_TOKEN` — сменить токен бота, `npm run dev` — локальный запуск без отправки сообщений.

## Подключение к Telegram

1. В Telegram открыть [@BotFather](https://t.me/BotFather), отправить `/newbot`, придумать имя и адрес бота
   (должен заканчиваться на `bot`). Токен бота этому приложению не нужен — храните его в секрете.
2. Кнопка приложения в чате с ботом: `/mybots` → ваш бот → **Bot Settings → Menu Button** →
   прислать адрес приложения (с `https://`) и название кнопки, например «Дневник».
3. Открыть чат с ботом и нажать кнопку слева от поля ввода.

Важно: данные хранятся в Telegram на конкретном телефоне и привязаны к адресу приложения.
Если адрес поменяется, старые данные по новому адресу видны не будут — перед сменой адреса
сохраните копию (экран «Данные» → «Скачать файл копии» или облако Telegram).
